\# TP Final Laboratorio de Datos II - Proyecto Cervecera



\## Configuración del Entorno Reproducible



Sigue estos pasos para clonar el repositorio y configurar el entorno virtual:



1\. \*\*Clonar el repositorio:\*\*

```bash

git clone \[https://github.com/Geronimo472/TP-Final-LAB-DATOS.git](https://github.com/Geronimo472/TP-Final-LAB-DATOS.git)

cd TP-Final-LAB-DATOS

```



2\. \*\*Crear y activar el entorno con Conda:\*\*

```bash

conda create -n cervecera\_env python=3.12

conda activate cervecera\_env

```



3\. \*\*Instalar dependencias:\*\*

```bash

pip install uv

uv pip install -r requirements.txt

```
